    Dépôts GitHub

    Dépose un dossier ou un ZIP : son contenu devient la racine du dépôt, sous-dossiers compris.

    1Dépôt

    Choisis dans la liste ou saisis propriétaire/nom.
    Elle part de la branche choisie ci-dessus.
    Le dépôt est créé sur ton compte et ne contient que tes fichiers. Il faut un jeton classique avec la portée « repo ».

    2Fichiers

    Aucun fichier choisi Glisse un dossier ou un ZIP ici, ou utilise les boutons.
    Sur Android, le navigateur ne propose parfois pas les dossiers : dans ce cas, envoie un ZIP.
    Options des fichiers

      3Publication

      Désactivé : les fichiers du dépôt qui ne sont pas dans ton dossier restent en place.

      Connexion GitHub

      Utilisé par l'onglet Dépôts. S'il est vide, le jeton ci-dessus sert aussi pour les dépôts. Le jeton reste dans ton navigateur et n'est envoyé qu'à api.github.com. Pour publier dans des dépôts, il lui faut le droit « Contents » en écriture (ou la portée « repo »). Pousser un fichier de .github/workflows demande aussi la portée « workflow ».
